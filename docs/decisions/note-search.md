# 노트 검색

## Decisions

- 검색은 현재 폴더가 아닌 로그인한 사용자의 보관함 전체를 대상으로 한다. 제목과 본문을 함께 찾는다.
- 일반 문서·Markdown의 글과 코드, 그림판의 모든 글상자를 검색한다. 서식 태그나 스타일 값은 검색하지 않는다.
- 휴지통과 다른 사용자의 노트, 공유 링크로 읽은 노트는 검색 대상이 아니다. 서버에 저장된 내용으로 검색하며 미저장 초안은 합치지 않는다.
- 결과에는 제목·형식·폴더 경로와 일치 문구 주변을 보여준다. 결과에서 노트를 열고 돌아와도 검색어를 유지한다.

## Why

제목과 폴더가 기억나지 않아도 본문 일부로 다시 찾는 것이 목적이다. 현재 폴더로 한정하면 폴더를 먼저 기억해야 한다. 그림판도 글상자는 사용자가 입력한 글이므로 세 형식 모두 같은 검색에 포함한다. 휴지통은 삭제한 자료를 다시 일반 보관함에서 만나지 않도록 제외한다. 초안은 특정 브라우저에만 있으므로 서버 저장본과 섞으면 기기마다 검색 결과의 기준이 달라진다.

## Boundaries

- 첫 범위는 입력 문구의 부분 일치이며 영문 대소문자는 구분하지 않는다. 초성·오타·유의어·OCR 검색은 포함하지 않는다.
- 폴더 이름 검색과 폴더·형식·날짜 필터, 문서 안의 다음 일치 위치 이동은 별도 범위다.

## Reconsider when

- 결과가 많아 찾기 어렵다는 실제 사용 피드백이 있을 때 폴더 범위와 필터를 검토한다.
- 이미지·필기에서 찾는 요구가 반복될 때 OCR의 비용과 범위를 별도로 결정한다.

## Still-rejected alternatives

- 현재 폴더만 검색하기 — 폴더를 기억하지 못하는 사용 상황을 해결하지 못한다.
- 목록 미리보기만 검색하기 — 본문 뒷부분과 두 번째 이후 그림판 글상자를 놓친다.
