# React 19 Server Components 정리

## 왜 쓰는가

- 컴포넌트 코드가 브라우저 번들에 안 들어간다
- 데이터 접근이 서버에서 끝나서 물 흐르듯 이어진다
- 단, `useState`는 못 쓴다. 상태가 필요하면 경계를 나눈다

```tsx
export default async function Page() {
  const notes = await db.note.findMany()
  return <NoteList items={notes} />
}
```

## 헷갈렸던 것

> "서버 컴포넌트"와 "서버 액션"은 다른 이야기다.

| 구분 | 실행 시점 | 상태 |
| --- | --- | --- |
| 서버 컴포넌트 | 렌더 | 없음 |
| 클라이언트 컴포넌트 | 렌더 + 이후 | 있음 |
