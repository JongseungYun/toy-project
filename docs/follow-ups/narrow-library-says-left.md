# 좁은 화면에서 목록이 위로 쌓이는데 안내는 "왼쪽"을 가리킨다

## 증상

폭 390px에서 보관함을 열면 좌우 두 칸이 위아래로 쌓인다. 그런데 아래 칸의 안내는
"왼쪽에서 노트를 고르세요"이고, 위에 쌓인 목록 칸은 노트 한 개 반 정도만 보일 만큼
짧다.

## 관찰한 근거

사람 검토(a2d11ea)에서 390×844 창으로 로그인해 확인했다. 문구는 아홉 개 사전의
`library.pickTitle`("왼쪽에서 노트를 고르세요")과 `pickBody`("… 왼쪽 위의 빈 카드를
누르세요")다.

## 짐작하는 원인

문구가 넓은 화면의 좌우 배치를 전제로 쓰였다. 목록 칸의 높이도 좁은 화면에서 따로
정해 두지 않았다.

## 해본 것

고치지 않았다. `docs/decisions/ui-composition.md`가 요구하는 것은 "정보의 중요도와
사용 순서를 보존한 채 column을 쌓는다"이고 쌓기 자체는 동작한다.

## 다음에 할 일
