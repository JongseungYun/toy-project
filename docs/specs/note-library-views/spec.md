# R05 중요 노트 고정·전체 노트 보기

2026-11-01 사용자가 R05 구현을 요청했다. 기존 검색과 폴더 정리를 유지하면서 자주 여는 노트와 폴더를 기억하지 못하는 노트에 접근하는 길을 제공한다.

## 범위와 동작

- 보관함에서 폴더별·전체 노트·고정한 노트 보기를 전환한다. 기본 진입은 기존 폴더별 보기다.
- 전체 노트는 모든 폴더와 하위 폴더의 내 노트를 한 번씩 보여준다. 고정한 노트는 그중 고정된 노트만 보여준다. 휴지통과 다른 계정의 노트는 제외한다.
- 노트 목록과 편집 화면에서 고정·해제할 수 있다. 저장이 성공한 상태만 확정해서 보여주며 실패하면 안내하고 재시도할 수 있다. 노트를 여는 링크와 고정 버튼은 별도로 동작한다.
- 고정은 계정에 저장되어 새로고침·재로그인·다른 기기에서도 유지된다. 고정·해제는 제목·본문과 편집 버전을 바꾸지 않는다.
- 폴더별·전체 목록은 고정한 노트를 먼저 보여주고 각 그룹 안에서는 기존 정렬을 따른다. 고정 목록도 기존 정렬을 사용할 수 있다.
- 전체·고정 목록에는 원래 폴더 경로를 표시한다. 그 목록에서 노트를 열면 목록·정렬을 유지하며, 좁은 화면의 목록으로 버튼도 같은 보기로 돌아간다.
- 폴더를 옮겨도 고정 상태를 유지한다. 휴지통에서는 나타나지 않고 복원하면 고정 여부도 함께 돌아온다. 고정 해제는 노트를 삭제하거나 옮기지 않는다.
- 각 보기에서 결과 없음·조회 실패·로딩 상태를 구분한다. 기존 전체 보관함 검색은 그대로 사용할 수 있다.

## 수용 기준

1. 서로 다른 폴더와 중첩 폴더의 일반 문서·Markdown·그림판을 전체 목록에서 원래 경로와 함께 찾고 연다.
2. 목록의 고정 버튼은 편집 화면을 열지 않으며, 고정·해제가 새로고침과 두 번째 로그인 세션에도 반영된다.
3. 고정 목록에는 고정한 노트만 나오고 해제하면 목록에서 빠진다. 전체·폴더 목록에서는 고정이 먼저이며 같은 그룹의 정렬이 유지된다.
4. 폴더 이동·삭제·복원 뒤에도 고정 상태와 경로가 일치한다. 다른 계정은 노트를 고정하거나 목록에서 읽을 수 없다.
5. 보기에서 노트를 열고 정렬을 바꾼 뒤 돌아와도 보기와 정렬이 유지된다. 좁은 화면에서도 제목·작업 도구·보기 전환이 가려지지 않는다.
6. 고정 저장 실패와 조회 실패를 사실대로 표시하고 재시도 후 정상 상태로 돌아온다.
7. 고정·해제 도중 작성한 미저장 제목·본문이 사라지거나 충돌 버전이 임의로 바뀌지 않는다.

## 기본값과 제외 범위

- 세 보기와 고정 우선 정렬은 이번 요청에 맞춘 조정 가능한 기본값이다. 수동으로 고정 순서를 바꾸는 기능은 포함하지 않는다.
- 전체·고정 보기에서 새 노트를 만들면 보관함 뿌리에 만든다. 기존 폴더별 보기에서는 현재 폴더에 만든다.
- 태그·스마트 폴더·폴더 자체 고정·일괄 정리·공유 화면의 고정 표시는 범위 밖이다.
- 화면 픽셀 비교는 브라우저에서 확인하며 실제 휴대폰 입력은 사용자 검증으로 보완한다.
