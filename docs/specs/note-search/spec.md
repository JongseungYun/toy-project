# R04 제목·본문 통합 검색

2026-10-30 사용자가 전체 보관함·세 형식의 글 검색 범위를 확정하고 구현을 요청했다.

## 목적과 범위

제목이나 담아 둔 폴더를 기억하지 못해도 본문의 문구로 노트를 찾아 이어 쓸 수 있다. 현재 폴더와 관계없이 내 보관함 전체의 제목·본문을 검색한다. 일반 문서와 Markdown의 글·코드, 그림판의 모든 글상자를 포함하며 본문 길이에 따른 미리보기 제한을 적용하지 않는다.

## 동작

- 보관함 공통 영역에서 검색어를 입력하고 실행한다. 검색 대상이 모든 폴더의 저장된 노트임을 표시한다.
- 공백뿐인 검색어는 조회하지 않는다. 연속된 공백과 줄바꿈은 한 칸으로 보고, 완성된 문구의 부분 일치를 찾으며 영문 대소문자를 구분하지 않는다.
- 일반 문서는 서식 태그·스타일 값을 제외한다. Markdown은 표시되는 글과 코드를 찾는다. `**회의** 준비`도 `회의 준비`로 찾을 수 있다. 링크 주소와 이미지 대체 문구의 별도 검색은 제외한다.
- 결과는 최근 수정 순으로 표시하고 동일 노트는 한 번만 표시한다. 제목·형식·원래 폴더 경로·일치한 본문 주변을 보여주고 일치 부분을 강조한다. 제목에만 일치하면 본문 앞부분을 보여준다.
- 결과에서 노트를 열어 편집할 수 있고 검색 결과로 돌아오면 검색어를 유지한다. 넓은 화면에서는 기존 목록·본문 구성을 재사용하고 좁은 화면에서는 한 칸씩 보여준다.
- 서버 저장본을 대상으로 한다. 저장 후 다시 검색하면 새 내용을 찾을 수 있다. 검색 중·결과 없음·조회 실패를 구분하며 실패는 같은 검색어로 재시도할 수 있다.

## 수용 기준

1. 서로 다른 폴더와 중첩 폴더의 세 형식을 제목과 본문 뒷부분의 문구로 각각 찾는다.
2. 서식이 나뉜 일반 문서·Markdown 문구, 코드, 그림판의 두 번째 이후 글상자도 찾는다.
3. 제목과 본문에 모두 일치해도 노트는 한 번만 나오며 영문 대소문자와 정규식·SQL 특수문자는 문자 그대로 처리한다.
4. 다른 계정과 휴지통의 노트는 나오지 않는다. 복원한 노트는 다시 검색하면 나온다.
5. 저장한 새 내용으로 다시 찾을 수 있고, 결과에서 노트를 연 뒤 돌아오면 같은 검색어가 유지된다.
6. 결과 없음과 조회 실패를 구분하고 실패 후 재시도로 복구한다.
7. 좁은 화면에서도 검색·결과·노트 열기가 가능하며 한글 조합 중 Enter가 검색을 조기 실행하지 않는다.

## 가정·제외·남은 위험

- 검색 실행 방식과 최근 수정 순 정렬은 조정 가능한 기본값이다.
- 휴지통·미저장 초안·오프라인 검색, OCR·초성·오타 검색, 고급 필터, R05의 고정·전체 보기, 문서 안 탐색은 범위 밖이다.
- 실제 휴대폰의 한국어 키보드 검증은 사용자 테스트로 보완한다. 자동화는 좁은 화면과 조합 이벤트를 확인한다.
- 첫 구현은 기존 저장본을 서버에서 읽어 검색한다. 대량 자료의 검색 성능 최적화·별도 색인은 이번 범위에 넣지 않는다.
